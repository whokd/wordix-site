# Wordix GitHub Pages Draft

This folder contains a small static site that can be published with GitHub Pages.

Suggested App Store URLs:

- Support URL: `https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/support.html`
- Marketing URL: `https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/`
- Privacy Policy URL: `https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/privacy.html`

Before publishing, replace every `YOUR_SUPPORT_EMAIL@example.com` placeholder with
the real support email address.

The public pages mention FreeDict as the dictionary-data source and point dictionary
content issues to <https://freedict.org/>.

To publish from GitHub:

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to Pages.
4. Set the source to the `docs` folder on your main branch.
5. Save and wait for GitHub Pages to publish the site.
