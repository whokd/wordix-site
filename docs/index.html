How it works

  • Pick two or more languages.
  • Start with a suggested word or enter your own.
  • Build a new valid word from the available letters.
  • Follow the translation into the next language.
  • Save useful word pairs and practice them later.

Modes for every pace

Explore mode is calm and untimed. Challenge mode adds a timer, score, coins, and powers for quicker rounds when you want more pressure.
